# FUXA Imports

Reference/import artifacts for Stonehenge FUXA HMI work.

These files are used to build or compare known FUXA device/panel definitions. The MVC app should embed only cataloged panels through `Services/StaticEngineeringPanelCatalog.cs` and the app-local FUXA proxy path.

Do not treat this folder as a generic upload surface. FUXA project edits should be deliberate and repeatable through tooling.
