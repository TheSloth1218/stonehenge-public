# FUXA Tools

Helper scripts for preparing the Stonehenge FUXA environment.

- `install-auto-hmis.js` installs/generated known HMI panel entries.
- `patch-fuxa-main.js` applies FUXA UI/runtime patches needed for embedded use.
- `stonehenge-hmi-proxy.js` supports the constrained HMI proxy path.

These scripts are for controlled setup. They should not create broad external FUXA access or expose the FUXA editor/lab as an operator feature.
